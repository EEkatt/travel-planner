# Исследование аналогов

## Статус

Черновик. Нужна отдельная проверка функций, цен, платформ и ограничений.

## Цель исследования

Понять, какие travel-приложения уже закрывают похожие сценарии, где они сильны, где неудобны для личного использования и какую нишу может занять проект.

## Предварительные аналоги

| Продукт | Сильная сторона | Что проверить подробнее |
| --- | --- | --- |
| TripIt | Организация travel-планов, рейсов, броней и документов в одном месте | Насколько удобно вручную добавлять данные из разных источников, какие функции платные |
| Wanderlog | Планирование поездок, маршруты, места, совместное планирование | Насколько хорошо закрывает рейсы, отели, заметки и мобильное использование |
| Google Maps / Google Travel | Карты, места, списки, travel-интеграции Google | Насколько единый опыт для маршрута, рейсов, броней и заметок |
| Roadtrippers | Маршруты, точки интереса, road trip planning | Насколько подходит не только для автомобильных путешествий |
| Polarsteps | Дневник путешествий, трекинг, заметки, визуальная история | Насколько подходит для планирования до поездки |
| Flighty | Сильное отслеживание рейсов | Не решает маршрут, отели и заметки как единое путешествие |
| Яндекс Путешествия | Покупка и хранение поездок внутри экосистемы | Можно ли удобно добавить свои билеты и брони из других источников |

## Предварительный вывод

Рынок уже содержит сильные отдельные решения:

- рейсы и travel organizer: TripIt, Flighty;
- маршруты и места: Wanderlog, Google Maps, Roadtrippers;
- дневник и история поездки: Polarsteps;
- бронирование внутри экосистемы: Яндекс Путешествия и другие travel-сервисы.

Потенциальная ценность проекта - не в том, чтобы сразу заменить все эти продукты, а в личном едином пространстве поездки, где можно вручную собрать данные из любых источников и использовать их вместе.

## Возможная дифференциация

- Простое ручное добавление данных из любых источников.
- Единая структура поездки: маршрут, рейсы, отели, заметки, напоминания.
- Mobile-first использование во время поездки.
- LLM как помощник поверх уже собранного контекста поездки, а не отдельный чат без связи с маршрутом.
- Фокус на личном и семейном использовании, а не на продаже travel-услуг.

## Что нужно проверить

- Какие функции доступны бесплатно и платно в TripIt, Wanderlog, Roadtrippers, Polarsteps и Flighty.
- Есть ли ручное добавление рейсов, отелей и заметок.
- Есть ли привязка заметок к конкретному месту или этапу.
- Есть ли общий экран поездки.
- Есть ли офлайн-доступ.
- Есть ли совместное редактирование.
- Есть ли LLM-функции.
- Какие есть ограничения по странам и картам.
