## Решения

## 2026-06-28 - Начать с travel-приложения для единого планирования поездки

Status: Accepted

Context:
Пользователь хочет приложение, где маршрут, точки на карте, рейсы, брони отелей, заметки и будущая LLM-помощь находятся в одном месте. Текущий процесс раздроблен между картами, ChatGPT, сервисами бронирования, почтой и заметками.

Decision:
Проект развивается как приложение для планирования и сопровождения путешествий. Первая версия ориентирована на личное использование, семью и друзей.

Consequences:
MVP должен проверить базовую ценность единого пространства для поездки. LLM, автоматический импорт билетов и броней, совместное редактирование и покупка travel-услуг откладываются до следующих этапов.

## 2026-06-28 - Основной формат продукта: мобильное приложение

Status: Proposed

Context:
Приложение должно использоваться во время путешествия, когда пользователь чаще всего открывает телефон. Web-версия может быть удобна для планирования из дома, но не является главным форматом первой версии.

Decision:
Считать мобильное приложение основным целевым форматом. Технический стек пока не выбран: нужно сравнить Swift/iOS, React Native/Expo, Flutter и PWA.

Consequences:
При проектировании MVP нужно учитывать мобильный интерфейс, офлайн-доступ, push/local notifications, карты и локальное хранение данных.

Links:
- `docs/02_technical_requirements.md`
- `docs/09_open_questions.md`

## 2026-06-28 - LLM не входит в MVP, но является стратегической функцией

Status: Accepted

Context:
LLM-помощник является важной частью видения продукта: подбор мест, маршруты, списки вещей, советы по стране, проверка плана и структурированное сохранение результатов. При этом базовая ценность должна быть проверена без сложной LLM-интеграции.

Decision:
В MVP сфокусироваться на карте, маршрутах по дням, бронях и заметках. LLM оставить для следующих версий, но не проектировать модель данных так, чтобы LLM было сложно добавить позже.

Consequences:
MVP остается реализуемым, а будущий LLM-модуль сможет работать поверх уже собранного контекста поездки.
