# Archived Early Documents

## Status

Archived / legacy.

## Important

Files in this directory are early project drafts. They are kept for historical context only and are not the current source of truth.

Do not use `docs/` files to make current product, architecture, MVP, backlog, quality, or implementation decisions.

## Current Sources Of Truth

Use these directories instead:

- `product/` - current product vision, brief, personas, and journey.
- `requirements/` - current requirements, use cases, MVP, and backlog.
- `architecture/` - current architecture, decisions, implementation slices, security/resilience, and provider research.
- `testing/` - current quality requirements, test strategy, CI gates, release checklist, and QA system.
- `process/` - current project principles, Definition of Done, change log, and glossary.
- `agents/` and `prompts/` - current agent system definitions and prompts.

If an archived file conflicts with a current file, the current file wins.
