# Testing Agents

This directory contains instructions for agents responsible for quality and testing.

## Initial Roles

- `quality_lead` - owns the testing system, quality gates, risk-based priorities, and review of QA outputs.
- `qa_engineer` - designs manual and exploratory tests, validates flows, and reports defects.
- `test_automation_engineer` - designs and implements automated test infrastructure and automated regression checks.
- `code_quality_reviewer` - reviews maintainability, structure, TypeScript quality, and testability.
- `security_reviewer` - reviews privacy, security, logging, permissions, dependencies, and local data risks.
- `release_qa` - owns release candidate smoke, regression evidence, and known-issue reporting.

The main workflow is described in `../15_agent_workflow.md`.
