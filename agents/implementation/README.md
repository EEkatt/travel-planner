# Implementation Agents

This directory contains instructions for agents responsible for practical implementation spikes and mobile foundation work.

## Initial Roles

- `mobile_expo_engineer` - implements and validates the Expo/React Native mobile foundation, navigation, storage spikes, development builds, and runnable app scaffolding.
- `map_provider_engineer` - validates map SDKs, offline map packs, tile/style providers, attribution, pricing, API key constraints, and map/search adapter proofs.

The main workflow is described in `../15_agent_workflow.md`.
