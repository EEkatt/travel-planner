# User Stories

## Status

Draft

## MVP Stories

- As a traveler, I want to create a trip so that I can keep all travel information in one place.
- As a traveler, I want to add places from any source to a map so that I can see what I want to visit.
- As a traveler, I want to group places by day so that I can plan each day of the trip.
- As a traveler, I want to see all places on one map so that I understand the whole trip.
- As a traveler, I want to open a place in an external map app so that I can navigate without the product building its own routing.
- As a traveler, I want to add flight information manually so that I do not lose stable ticket details.
- As a traveler, I want to add hotel booking information manually so that I can quickly find where I live.
- As a traveler, I want to add notes so that I can remember important details.
- As a traveler, I want to use checklists so that I do not forget things before the trip.
- As a traveler, I want quick access to today's plan, housing, flights, notes, and checklists so that I can use the app during the trip without searching through multiple tools.
- As a traveler, I want saved trip details to remain available without a network connection if technically feasible so that I can access critical information while traveling.

## Later Stories

- As a traveler, I want an LLM assistant to suggest places so that I can discover better routes.
- As a traveler, I want the app to optimize my route so that I spend less time moving between places.
- As a traveler, I want to share my trip with friends so that we can plan together.
- As a traveler, I want to reuse someone else's route so that I can plan faster.
- As a traveler, I want to attach booking files so that all documents are available in the trip.
- As a traveler, I want automatic flight and booking import so that I can reduce manual entry.
- As a traveler, I want live flight tracking so that I can react to delays and gate changes.
- As a traveler, I want to book flights, hotels, or activities inside the app so that planning and purchase happen in one product.
- As a traveler, I want full offline maps so that I can navigate without internet.

## MVP Story Boundaries

- Flight stories cover manual storage of stable itinerary data only, not live tracking, disruption alerts, aircraft history, or delay prediction.
- Map stories cover trip visualization and external navigation handoff only, not route optimization or offline routing.
- Collaboration stories stay out of MVP; sharing can be revisited after personal/family use validates the core plan.
