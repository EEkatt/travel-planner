# Archived Early Specs

## Status

Archived / legacy.

## Important

Files in this directory are early draft specs. They are kept for historical context only and are not the current source of truth.

Do not use `specs/` files to make current MVP, backlog, roadmap, architecture, quality, or implementation decisions.

## Current Sources Of Truth

Use these directories instead:

- `requirements/` - current requirements, MVP, backlog, user stories, and use cases.
- `architecture/` - current architecture and accepted decisions.
- `product/` - current product framing and user journey.
- `testing/` - current quality and testing system.

If an archived file conflicts with a current file, the current file wins.
